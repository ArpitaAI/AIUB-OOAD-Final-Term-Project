# Facebook Management System

A Facebook-style social media management system developed as an Object-Oriented Analysis and Design (OOAD) project.

The system models the core functionalities of a modern social networking platform, including user profile management, content sharing, friend connections, groups, events, messaging, reactions, notifications, privacy controls, moderation, and administrative management.

The project represents four major actors: User, Admin, Moderator, and Developer, with different responsibilities and system access.

## Key Features

- User profile creation and management
- Post creation and content sharing
- Friend request and connection management
- Group creation and membership management
- Event creation and participation
- Private messaging
- Likes, comments, and sharing
- Notification management
- Privacy and content visibility controls
- Admin and moderator content management
- Developer and system maintenance workflows

## System Actors

- User
- Admin
- Moderator
- Developer

The Facebook Management System is designed around several modular services:

- User Profile Service
- Post Service
- Friend Service
- Group Service
- Event Service
- Messaging Service
- Notification Service
- Privacy Service
- Reaction Service

## Project Purpose

The purpose of this project is to demonstrate the practical application of Object-Oriented Analysis and Design principles in designing a large-scale social media management system.

The project focuses on requirement modeling, user interactions, system workflows, object relationships, role-based access, modular architecture, and UML-based system design.
